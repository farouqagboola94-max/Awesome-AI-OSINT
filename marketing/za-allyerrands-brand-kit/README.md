# Za.allyErrands — Brand IP Kit (50 assets)

Complete visual identity: 50 master plates in `png/` (ip01–ip50), generated
from `kit-build.js` + `kit-build2.js` (HTML/SVG masters, fully editable).

- Brand book (living document): published as a Claude artifact; source in `brand-book-src.html`
- Adobe Express brand board (5 editable slides): exported via the Adobe connector
- Canva editable designs: logo, IG post, flyer, business card (links in brand book)
- Regenerate: `node kit-build2.js && node kit-render.js`

System: Midnight Forest #05100A / Deep Moss #0A1F12 / Signal Green #16E56B /
Volt Lime #C6FF4A / Mint Paper #EAFFF2 — Anton (display) + Archivo Black (body).
Mascot: "Ally — your double."
