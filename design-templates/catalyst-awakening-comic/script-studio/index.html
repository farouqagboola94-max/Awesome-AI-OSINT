Panel and image framework

The story is read directly from the published website. Its wording and sequence aren’t rewritten. Source beats are grouped into working panels, with up to four groups on a working page. These aren’t the comic’s final printed page numbers.

For every panel group, set the frame, action, continuity reference and visual priority. The Image production brief then creates a ready-to-use prompt that carries only those approved details into image creation. Add lettering after the artwork, never inside the image prompt.

Existing instructions for spreads, grids and multi-panel sequences are preserved. A working group may contain several drawable moments. Split those moments into image panels before final lettering.

Notes are saved only in this browser. Export a notes backup to move them to another device. Importing a backup never changes the published story.
