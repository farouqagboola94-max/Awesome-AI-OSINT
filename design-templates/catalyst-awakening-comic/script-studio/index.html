How this layout works

The story is read directly from the published website. Its wording and sequence aren’t rewritten. Source beats are grouped into working panels, with up to four groups on a working page. These aren’t the comic’s final printed page numbers.

Existing instructions for spreads, grids and multi-panel sequences are preserved. A working group may contain several draw-able moments. Use the layout and camera notes to plan them before final lettering.

Notes are saved only in this browser. Export a notes backup to move them to another device. Importing a backup never changes the published story.
